# Enter-Flow — Figma Make Design Prompt
**Enter-Fil Industrial Products · Order Management System with Real-Time Monitoring**
*For use with Figma Make AI · Full-System UI Generation Prompt*

---

## ── OVERVIEW & CONTEXT

Design a complete, production-ready web application UI called **Enter-Flow** — an ERP / Order Management System for **Enter-Fil Industrial Products**, a Philippine industrial filter manufacturing company. The system must serve three internal user roles (Management, Accounting/Finance, Floor/Production) and one external role (Client Portal). It is a **desktop-first web app** used on factory computers and office desktops.

Enter-Fil makes industrial air/oil separator filters. Their pain point: everything runs on paper, spreadsheets, and verbal updates. Enter-Flow digitizes the full pipeline from sales inquiry → quotation → job order → production → delivery → payment — all in one dashboard.

## ── PIPELINE RULES (ANNOTATE ON DESIGNS)

These behaviors must be annotated as design notes on the relevant screens:

1. **INQ → PO → JO lifecycle:** Cards only appear in one stage at a time. When advanced, they disappear from the previous column. The "Generate JO" button moves the card OUT of Sales board entirely.

2. **Production cleanup:** Completed JOs have an explicit "Archive" action. The production board only shows in-progress work. Completed = hidden from board, preserved in database.

3. **Client portal filtering:** Client X sees ONLY their own company's orders across all 4 portal tabs. No cross-client data leakage.

4. **Accounting tab consistency:** Invoice status = "Cleared" only after secretary manually approves uploaded receipt photos. Auto-calculations handle due dates but NOT payment approval.

5. **Inventory low-stock thresholds:** Adhesive < 3 sets · Box < 50 pcs · Filter Media < 5 rolls (local). System shows red badge on Inventory nav item when triggered.
